# 后台中文大白话优化 V1

基线：`ecac833fc74f501ddd12a2ed33e39f29be23a3e8`。本轮仅修改展示文字，不操作 Production。

## 审计范围和结论

扫描 `app/admin`、`components/admin`、`lib/admin`。
重点修复余额流水、供应商自动采购任务、自动任务运行状态，以及首页、商品规格与库存诊断、供应商绑定、支付和充值、回调、对账、用户、风险、邮件、退款、隐私请求、系统状态、请求追踪、审计和导航中的英文展示。

统一展示映射位于 `lib/admin/display-labels.ts`。真实枚举、请求参数和业务状态仍使用原值；例如筛选显示“账户充值”，提交 `account_recharge`；显示“余额增加”，提交 `credit`。供应商大写状态根据是否可再次尝试显示对应中文，不修改原状态。没有任务状态采集数据时显示“暂未获取”，不推断任务已经停用。

未知枚举保留原值并附中文说明。业务单号、供应商原始编号、版本 SHA、品牌/标准名称仍保留。诊断详情中的机器错误代码、升级文件名、结构化数据键属于排查证据，不改原值；不把它们当成普通运营状态标签。

## 日期范围

用户已明确选择保留现有日期接口。该接口仍接受日期字符串并使用原有时间边界；页面准确说明其对应北京时间当天 08:00 至次日 08:00。记录时间按北京时间显示。

**本轮没有把筛选改成北京时间 00:00 至 24:00，也不冒充已完成该功能。** 如需北京时间整天筛选，应另行设计并测试接口日期语义，不在文案补丁中悄悄改变查询范围。

## 安全验证

- 对修改前后代码做语法树比对：数据库查询、业务写入、请求调用及其参数不变。
- 未修改 API route、支付核心、数据库结构、migration、权限、金额计算、履约及状态机。
- 映射测试覆盖业务类型、方向、供应商状态、任务状态、布尔值、未知值和时间说明。
- 实际组件渲染测试验证中文标签与原始下拉选项值并存，且只读工作台没有写入控件。
- 原有回归测试仅更新展示文案断言，保留业务及安全断言。
