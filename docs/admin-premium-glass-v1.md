## 第三轮：收紧商品列表并推广后台共享视觉

- 商品首列由 292px 基准缩至 252px；标题与标签采用省略号，不撑宽表格。最多三枚标签单行显示，第四位为省略按钮。浮层通过 Portal 覆盖展示完整标签，不占列表行空间；支持悬停、焦点和点击。
- 移除商品列表的排序选择和排序列，保留分类管理原有排序、请求约定及历史数据。当前列表为十列，其余字段和操作不删除。
- 更多筛选位于重置下方，默认收起。1440px 时七项常用条件仍为一行，展开后保留原五项运营筛选。
- 横向滚动辅助条只在实际溢出时显示，消除无溢出时分页上方的固定空白。
- 供应商绑定改为距窗口四周留白的 26px 圆角面板；手机 22px。搜索与参数两栏按内容排列，标题与保存区固定。
- 所有后台页面继承同一浮动侧栏与顶部搜索框。移动导航为独立圆角面板。共享列表、统计、详情、空状态、错误状态统一冷灰蓝玻璃视觉，主按钮同步后台蓝色；危险/警告状态保留语义色。
- 供应商管理概览、目录及详情使用相同材质，工作区按钮可换行，手机搜索不再带强制 280px 最小宽度。
- 用户管理手机统计改为两列；共享高级筛选限制高度并可独立滚动，避免挤掉表格可视区域。
